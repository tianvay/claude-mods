# claude-mods

Mods for [Claude Code](https://claude.com/claude-code) by tianvay.

## Install all mods

Paste this into a terminal (PowerShell, bash or zsh):

```bash
claude plugin install braindump --marketplace tianvay/claude-mods; claude plugin install mod-switch --marketplace tianvay/claude-mods
```

Each mod installs at the user scope, so it's active in every Claude Code session from then on.

## Mods

| Mod | Version | Commands | What it does |
| --- | --- | --- | --- |
| [braindump](braindump) | 0.1.0 | `/braindump` | Talk it out like you would to a friend; Claude asks a few questions and turns it into a clear prompt for you to review. |
| [mod-switch](mod-switch) | 0.1.0 | `/mods` | A side panel listing your mods, with an on/off switch for each. |

## Install one mod

**braindump** — in a Claude Code session type `/plugin install braindump --marketplace tianvay/claude-mods`, or from a terminal:

```bash
claude plugin install braindump --marketplace tianvay/claude-mods
```

**mod-switch** — in a Claude Code session type `/plugin install mod-switch --marketplace tianvay/claude-mods`, or from a terminal:

```bash
claude plugin install mod-switch --marketplace tianvay/claude-mods
```

In the Claude desktop app you can also click **+** next to the prompt box, then **Plugins** → **Add marketplace** with `tianvay/claude-mods`, then **Add plugin**.

## Notes

- **mod-switch** pauses a mod's slash commands and skills for the current session only. Mods that only use hooks can't be paused from the panel.
